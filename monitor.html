Alertas da Evolution

Receba avisos no Telegram quando Docker, API ou WhatsApp ficarem indisponíveis.

Acesso administrativo

Use a chave do login administrativo da Evolution. Ela fica somente na memória desta página.

Estado do monitor

Verificação a cada minuto. Alertas após duas falhas consecutivas e repetição a cada 30 minutos. Recuperação gera um aviso. O estado “saudável” não comprova entrega dos boletos.

Docker e API

Inicie uma conversa com o bot ou adicione-o ao grupo. Token vazio mantém o valor já salvo.

Instâncias WhatsApp

Marque somente as instâncias que devem permanecer conectadas. Token ou chat vazios usam o destino configurado em Docker e API.

Para manutenção planejada, o administrador pode pausar a recuperação criando /run/vpscloud-evolution-maintenance. Remova esse arquivo ao concluir.

Como criar seu bot e grupo no Telegram

  1. Crie o bot. Abra o @BotFather oficial, toque em Iniciar e envie /newbot. Escolha um nome e um nome de usuário disponível terminado em bot, por exemplo MinhaEmpresaAlertasBot.
  2. Copie o token. O BotFather entregará a chave de acesso do bot. Cole-a no campo Token do bot deste painel. Guarde-a como senha; não publique nem compartilhe capturas com ela.
  3. Crie o grupo de alertas. No Telegram, escolha Novo grupo e dê um nome, como Alertas da empresa. Abra as informações do grupo, escolha Adicionar membros e adicione o bot que acabou de criar. O bot precisa ter permissão para enviar mensagens. Não é necessário desativar o modo de privacidade para receber nossos alertas.
  4. Envie um comando no grupo. Digite /start@MinhaEmpresaAlertasBot, substituindo pelo nome de usuário do seu bot. Isso permite localizar o grupo mesmo com o modo de privacidade ativado.
  5. Localize o Chat ID. Consulte o método getUpdates da API oficial do Telegram para seu bot. O endereço tem o formato https://api.telegram.org/botSEU_TOKEN/getUpdates. Substitua somente SEU_TOKEN. Esse endereço contém sua chave: use apenas em dispositivo de confiança e não compartilhe o link ou a resposta. Procure o comando que enviou e, dentro de message → chat, copie o campo id. IDs de grupos são negativos e podem começar com -100. Não copie o from.id do remetente nem o ID do bot.
  6. Salve e teste. Cole o ID completo, incluindo o sinal de menos, em Chat ID. Clique em Salvar e testar. A confirmação aparecerá na tela e a mensagem deverá chegar ao grupo.
  7. Escolha as instâncias. Marque as que deseja monitorar. Para usar o mesmo bot e grupo de Docker/API, deixe token e chat opcionais vazios. Para outro destino, preencha os campos da instância e clique em Salvar e testar nessa instância.
O grupo não apareceu ou o teste falhou?

Envie novamente o comando dirigido ao bot e consulte as atualizações. Se o bot já for usado por outro sistema com webhook ou consulta de atualizações, não remova essa configuração: prefira criar um bot exclusivo para os alertas ou peça o Chat ID ao administrador. Confira o sinal negativo do ID, o token e se o bot está no grupo e pode enviar mensagens.
