Alertas da Evolution

Receba avisos no Telegram quando Docker, API ou WhatsApp ficarem indisponíveis.

Acesso administrativo

Use a chave do login administrativo da Evolution. Ela fica somente na memória desta página.

Estado do monitor

Verificação a cada minuto. Alertas após duas falhas consecutivas e repetição a cada 30 minutos. Recuperação gera um aviso. O estado “saudável” não comprova entrega dos boletos.

Docker e API

Inicie uma conversa com o bot ou adicione-o ao grupo. Token vazio mantém o valor já salvo.

Instâncias WhatsApp

Marque somente as instâncias que devem permanecer conectadas. Token ou chat vazios usam o destino configurado em Docker e API.

Para manutenção planejada, o administrador pode pausar a recuperação criando /run/vpscloud-evolution-maintenance. Remova esse arquivo ao concluir.
